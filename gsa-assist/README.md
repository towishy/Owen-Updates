# GSA Assist Updates

`update.json`은 GSA Assist가 플랫폼별 최신 공개 버전을 확인하는 schema v3
`check-only` manifest다. 설치 파일, 자동 업데이트 feed, checksum과 앱 package는
이 저장소에 두지 않는다.

| 플랫폼 | 최신 버전 | 배포 위치 |
| --- | --- | --- |
| Windows x64 | 0.1.29 | 비공개 제품 GitHub Release |
| Apple Silicon macOS | 0.1.27 | 비공개 제품 GitHub Release |

GSA Assist는 이 manifest에서 버전 정보만 읽는다. 다운로드와 설치는 자동으로
시작하지 않으며 이 공개 저장소는 바이너리 URL을 제공하지 않는다.

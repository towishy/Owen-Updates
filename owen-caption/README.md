# Owen Caption

공식 지원 페이지입니다. 지원 언어: 한국어·영어.

Owen Caption은 영어 음성과 로컬 영상에서 영어·한국어 자막을 생성하는 Windows/macOS 앱입니다.
실시간 입력, 영상 파일, 폴더 작업, SRT 저장과 번역 사전을 제공합니다.
기본 번역에는 로컬 모델을 사용하며 최초 사용 시 모델 다운로드와 지원되는 GPU가 필요합니다.
사용자가 외부 AI 번역을 선택하면 자막과 번역 맥락이 지정한 서버로 전달될 수 있습니다.
자동 전사와 번역 결과는 중요한 내용에 사용하기 전 원본과 대조하세요.

현재 Windows 배포 구성에는 독립 재생 앱 [Owen Player](../owen-player/README.md)가 포함됩니다.
스토어 등록 및 판매 여부는 실제 Microsoft Store 제품 페이지를 기준으로 합니다.
이 저장소에는 설치 파일이나 자동 업데이트 바이너리를 게시하지 않습니다.

- 모델 설치 실패: 네트워크·디스크 여유와 앱의 모델 상태를 확인합니다.

- 외부 AI 오류: 선택한 제공자, 서버 주소, 모델명과 API 키 상태를 확인합니다. 키 자체는 지원 요청에 포함하지 않습니다.
- 자막 검토: 자동 생성 결과에는 누락이나 오역이 있을 수 있습니다. 원본과 비교해 수정합니다.

## English

Owen Caption creates English and Korean subtitles from English audio and local videos.
Local models are used by default. Initial model downloads and supported hardware are required.
Optional external AI translation sends subtitle text and translation context to the selected server.
For support, contact [owen@sarang.day](mailto:owen@sarang.day) with your app/OS versions and steps to reproduce the issue.
Do not send API keys or sensitive media. Support is available in Korean and English.
Windows distribution includes the companion [Owen Player](../owen-player/README.md). Check the Microsoft Store for actual availability; this support page does not confirm a Store release.
For model setup issues, check network access, free disk space and model status. Review automatic subtitles against the original.
See the [Privacy Policy](PRIVACY.md), effective 2026-09-07. Support correspondence is deleted within 90 days after an enquiry closes, except where legally required.
This repository does not host installers or update binaries.

# Owen Player

공식 지원 페이지입니다. 지원 언어: 한국어·영어.

Owen Player는 로컬 영상과 영어·한국어 SRT를 재생하는 독립 플레이어입니다.
자막 언어·크기·위치 조절, 영상 위 그리기, 확대 렌즈, PNG 프레임 저장과 영역 영상 캡처를 제공합니다.
기존 자막을 재생하는 데 번역 모델이 필요하지 않습니다.
새 자막 생성과 번역은 [Owen Caption](../owen-caption/README.md)의 기능입니다.
현재 Windows 배포 구성에서는 두 앱이 함께 제공되며 독립적인 Store 제품 등록 여부는 미정입니다.
이 저장소에는 설치 파일이나 자동 업데이트 바이너리를 게시하지 않습니다.

## 지원

문의: [owen@sarang.day](mailto:owen@sarang.day)

앱·운영체제 버전, 영상 형식과 오류 문구, 재현 순서를 알려주세요.
민감한 영상이나 저작권자의 허가가 없는 자료는 보내지 마세요.

- 자막이 보이지 않으면 영상 옆 `자막` 폴더의 언어별 SRT 또는 직접 선택한 SRT를 확인합니다.
- 화면 캡처는 영상 폴더의 `Screenshot` 폴더에 저장됩니다. 쓰기 권한과 디스크 여유를 확인합니다.
- 영상 캡처를 시작한 뒤 중지하고 저장 명령을 실행합니다. 녹화 중인 표시만으로 파일 저장 완료를 의미하지 않습니다.
- 영상과 SRT의 시점이 맞는지 확인하세요. Player가 자동으로 새 자막을 번역하는 것은 아닙니다.

[개인정보 처리방침 / Privacy Policy](PRIVACY.md)을 확인하세요. 시행일: 2026-09-07.

## English

Owen Player plays local video with English and Korean SRT subtitles and includes drawing, magnification and capture tools.
Existing subtitle playback does not require translation models. Subtitle generation is provided by Owen Caption.
Contact [owen@sarang.day](mailto:owen@sarang.day) with your app/OS versions and reproduction steps.
Support is available in Korean and English. Do not send secret keys or sensitive media.
Check language-specific SRT files in the folder named `자막` beside your video, or open an SRT directly. PNG frames are saved in `Screenshot` beside the video.
For video captures, stop recording and use the save command; a recording indicator alone does not mean a file was saved.
See the [Privacy Policy](PRIVACY.md), effective 2026-09-07. Support correspondence is deleted within 90 days after an enquiry closes, except where legally required.
This repository does not host installers or update binaries. This support page does not confirm a Store release.

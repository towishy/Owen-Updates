# GSA Dashboard Updates

`update.json`은 GSA Dashboard가 플랫폼별 최신 버전을 확인하는 공개 제품 매니페스트다. schema v3의 모든 플랫폼은 `check-only`이며 설치 파일이나 자동 업데이트 feed URL을 제공하지 않는다.

Windows 설치와 업데이트는 향후 Microsoft Store를 기본 경로로 사용한다. Store 전환 전 설치 파일은 제품별 외부 배포 경로에서 제공한다. 이 저장소에는 EXE, NuGet package, updater feed, checksum 또는 GitHub Release 자산을 두지 않는다.
